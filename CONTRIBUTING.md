## Using the code directly to try your changes
1. Ensure you have **NOT** the plugin installed through the plugin manager
2. Get the code into your list of installed plugins manually, by either
    a) Clonning the code into `<your valut directory>/.obsidian/plugins`, or
    b) Linking your working copy of the plugin into `<your valut directory>/.obsidian/plugins`
3. Once inside, run
```bash
$ npm i
$ npm run build
```
4. Go to Settings in Obsidian and, from there to the list of `Community plugins`
5. Click the `Reload plugins` button, to the right of the `Installed plugins` label
6. Enable `Helix Keybindings`
